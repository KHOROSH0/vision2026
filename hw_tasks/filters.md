**Примечание**. Во всех задачах рекомендуется использовать прямой доступ к пикселям, свертка реализуется при помощи четырех вложенных циклов.


**Задача 1.**
Реализовать функцию `def filter_2d(img, kernel)`, которая принимает на вход одноканальное изображение в оттенках серого и ядро фильтра в виде квадратной матрицы. Функция реализует свертку входного изображения с заданным ядром и возращает результат в качестве выхода функции. Для валидации можно использовать функцию `cv2.filter2d`.


**Задача 2.**
Реализовать функцию `def median_filter(img, ksize)`, которая реализует медианную фильтрацию входного изображения с окном размера `ksize` (только нечетные значения). Для валидации можно использовать функцию `cv2.medianBlur`.
